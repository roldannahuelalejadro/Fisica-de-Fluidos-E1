# Física de Fluidos

Repositorio organizado por trabajos prácticos y material de consulta.

## Estructura

- `Tp1/`: entrega, problemas individuales, código auxiliar y borradores del primer trabajo práctico.
- `Tp2/`: entrega y desarrollos del segundo trabajo práctico, incluido el problema 10 de Kuramoto–Sivashinsky.
- `Tp3/`: espacio reservado para el tercer trabajo práctico.
- `Guias/`: enunciados, ejercicios resueltos y notebooks de métodos numéricos usados como referencia.

## Convenciones

- Las versiones destinadas a entregar van dentro de `Entrega/`.
- Los desarrollos separados por problema se guardan en `Problemas/` o en la carpeta del problema correspondiente.
- Las versiones anteriores se conservan en `Borradores/`; no deben confundirse con la entrega vigente.
- Los datos que necesita un notebook se mantienen junto a ese problema cuando utiliza rutas relativas.
- No se versionan cachés de Python ni checkpoints de Jupyter.
